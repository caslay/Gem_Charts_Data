
Once connected, update package lists and upgrade packages:
```bash

```

---

### 1.3 Configure 2GB Swap Memory (Critical Guard Against OOM)
On 1GB RAM instances, Next.js build (`npm run build`) and memory spikes can trigger Out-Of-Memory (OOM) process termination. Creating a 2GB swap space guarantees stability:
```bash
sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile

# Make swap permanent across reboots
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab

# Optimize swappiness for server workload
sudo sysctl vm.swappiness=10
echo 'vm.swappiness=10' | sudo tee -a /etc/sysctl.conf
```

---

### 1.4 Chrony Millisecond Time Synchronization (Exchange Timestamp Precision)
Binance Futures API rejects requests if server clock drift exceeds `recvWindow` (typically 1000–5000ms). Install and configure `chrony` for microsecond-accurate timekeeping:
```bash
sudo apt install -y chrony
sudo systemctl enable --now chrony

# Verify clock synchronization status
chronyc tracking
```

---

### 1.5 UFW Firewall & Security Hardening
Lock down the server to allow only secure SSH connections:
```bash
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow 22/tcp
sudo ufw --force enable
sudo ufw status verbose
```
*(Note: Do NOT open port 3000 to the public internet. Access your dashboard privately via SSH Tunnel).*

### 3.2 Run Automated Binance API Connectivity & Balance Test
Execute our pre-built connectivity test script:
```bash
npx tsx -e "
import crypto from 'crypto';

const apiKey = process.env.BINANCE_API_KEY;
const apiSecret = process.env.BINANCE_API_SECRET;
const baseUrl = process.env.BINANCE_BASE_URL || 'https://fapi.binance.com';

async function testBinance() {
  console.log('🔍 Testing Binance Futures API connectivity...');
  const start = Date.now();
  const pingRes = await fetch(\`\${baseUrl}/fapi/v1/ping\`);
  const latency = Date.now() - start;
  console.log(\`✅ Binance Ping Success! Latency: \${latency}ms\`);

  if (!apiKey || !apiSecret) {
    console.log('⚠️ No API Key/Secret configured in environment.');
    return;
  }

  const timestamp = Date.now();
  const queryString = \`timestamp=\${timestamp}\`;
  const signature = crypto.createHmac('sha256', apiSecret).update(queryString).digest('hex');

  const accRes = await fetch(\`\${baseUrl}/fapi/v2/account?\${queryString}&signature=\${signature}\`, {
    headers: { 'X-MBX-APIKEY': apiKey }
  });

  if (accRes.ok) {
    const accData = await accRes.json();
    console.log('🎉 Binance Authentication SUCCESSFUL!');
    console.log(\`💰 Total Margin Balance: \${accData.totalMarginBalance} USDT/USDC\`);
    console.log(\`📊 Available Balance: \${accData.availableBalance} USDT/USDC\`);
  } else {
    const err = await accRes.json();
    console.error('❌ Authentication Failed:', err);
  }
}

testBinance();
"
```
