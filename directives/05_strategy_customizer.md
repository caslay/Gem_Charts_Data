## 2. Condition Sub-Dropdown Filters

To enable absolute precision for ICT (Inner Circle Trader) and SMC (Smart Money Concepts) models, several metrics support dynamic sub-dropdown filtering in the same row.

### A. Timeframe Filters (`timeframe`)
Applied to `FVG`, `PRICE_IN_FVG`, and `SMT_DIVERGENCE`. Restricts the evaluation to a specific chart timeframe.
- **`ANY`**: Evaluates across any active timeframe.
- **`5m`**: Restricts calculations to the 5-minute timeframe.
- **`15m`**: Restricts calculations to the 15-minute timeframe.

### B. Direction Filters (`direction`)
Applied to `FVG`, `PRICE_IN_FVG`, `SMT_DIVERGENCE`, `MSS`, and `BOS`. Gates the evaluation to bullish or bearish directions.
- **`ANY`**: Evaluates both bullish (BISI / Upward shifts) and bearish (SIBI / Downward shifts) directions.
- **`BULLISH`**: Filters strictly for Bullish conditions (e.g. Bullish FVG, Upward MSS/BOS).
- **`BEARISH`**: Filters strictly for Bearish conditions (e.g. Bearish FVG, Downward MSS/BOS).

### C. Confirmation Filters (`confirmation`)
Applied strictly to `MSS` to evaluate displacement sponsorship.
- **`CONFIRMED`**: Returns true strictly if the Market Structure Shift possesses displacement confirmation (taker volume sponsored Leg).
- **`UNCONFIRMED`**: Returns true if a minor/pending shift occurred without displacement sponsorship.
- **`ANY`**: Matches any structural shift regardless of sponsorship status.

### D. Retracement Filters (`retracement`)
Applied strictly to `PRICE_IN_OTE` to evaluate precise Fibonacci retracement levels.
- **`OTE`**: Optimal Trade Entry zone ($62\%$ to $79\%$ of the active stateful Dealing Range). Default corridor.
- **`FIB_50`**: Evaluates if the price has retraced *at least* 50% into the Dealing Range (Discount for buy setups, Premium for sell setups).
- **`FIB_60`**: Evaluates if the price has retraced *at least* 60% into the Dealing Range.
- **`FIB_705`**: Evaluates if the price has retraced *at least* 70.5% (the classic ICT OTE midpoint sweet-spot).
- **`FIB_79`**: Evaluates if the price has retraced *at least* 79% (Deep retracement).

### E. Evaluation Temporal Lock (`temporal`)
Governs the evaluation timing constraint for each specific logic row.
- **`TICK` (INSTANT)**: Evaluates on every single incoming WebSocket price tick. Essential for low-latency entry signals (e.g. `PRICE_IN_FVG`).
- **`CLOSE` (ON_CLOSE)**: Evaluates strictly when a candle close event is confirmed. Essential for filtering out intra-candle noise and spikes (e.g. `FVG` formation checks).

## 3. Global Strategy Settings Map

Strategy Settings govern how a trade is sized, executed, guarded, and managed upon an equation matching successfully.

| Parameter Group | Field / Option | Type / Options | Default | Description / Mechanical Rules |
| :--- | :--- | :--- | :--- | :--- |
| **Target Environment** | `Target Environment` | `BOTH`<br>`LIVE_ONLY`<br>`BACKTEST_ONLY` | `BOTH` | Enforces environment routing isolation. Prevents backtest-optimized research from firing live paper/production positions. |
| **Trade Direction** | `Trade Direction` | `LONG`<br>`SHORT` | `LONG` | Sets the setup bias. Long strategy triggers Buy orders. Short strategy triggers Sell orders. |
| **Temporal Mode** | `Temporal Mode` | `INSTANT`<br>`ON_CLOSE` | `INSTANT` | Gating rules: if set to `ON_CLOSE`, the entire strategy can only fire on closed candles. If set to `INSTANT`, triggers immediately mid-candle. |
| **Stop Loss Logic** | `Stop Loss Logic` | `Structural Swing`<br>`Last Candle High/Low`<br>`Manual Pips` | `Structural Swing` | 1. **Structural Swing:** Automatically places SL behind the active Dealing Range extreme (hard invalidation).<br>2. **Last Candle High/Low:** Places SL at the preceding candle's extreme price.<br>3. **Manual Pips:** Hardcoded `$10.00` index price offset. |
| **Take Profit Logic** | `Take Profit Logic` | `Nearest Order Book Magnet`<br>`PDH/PDL Target`<br>`Manual Pips` | `Nearest Order Book Magnet` | 1. **Nearest Magnet:** Targets the nearest resting BSL/SSL liquidity magnet array index.<br>2. **PDH/PDL Target:** Targets Previous Day High (for long) or Low (for short).<br>3. **Manual Pips:** Automatically calculates a strict `1:2` Risk-to-Reward (RR) target. |
| **Risk per Trade (%)** | `Risk per Trade (%)` | `number` | `1.0` | Sets dynamic position sizing. Automatically computes order size based on the Stop Loss distance so that invalidation loses exactly this % of capital balance. |

## 4. Operational Setup Integration Examples

### Example 1: Classic ICT Silver Bullet / FVG Mitigation (Long)
An institutional setup looking for price to retrace into a 5-minute discount Fair Value Gap during active bullish market trends.

* **Trade Direction:** `LONG`
* **Temporal Mode:** `INSTANT`
* **Stop Loss:** `Structural Swing` (SL set below range low)
* **Take Profit:** `Nearest Order Book Magnet` (Targets resting BSL)
* **Equation Conditions:**
  1. `MARKET_TREND` == `BULLISH` [CLOSE]
  2. `LOCAL_PRICING` == `DISCOUNT` [TICK]
  3. `PRICE_IN_FVG` [5m, BULLISH] `IS TRUE` [TICK]
  4. `DISPLACEMENT` == `ANY` [CLOSE] (Ensures leg has momentum)

### Example 2: Institutional Trend Reversal / sponsored MSS (Short)
A high-probability SMC reversal setup triggered when price violently breaks a structural swing high with volume sponsorship, and is currently priced in Premium.

* **Trade Direction:** `SHORT`
* **Temporal Mode:** `ON_CLOSE`
* **Stop Loss:** `Structural Swing` (SL set above swing high)
* **Take Profit:** `Nearest Order Book Magnet` (Targets resting SSL)
* **Equation Conditions:**
  1. `MARKET_TREND` == `BEARISH` [CLOSE] (Trend has flipped to bearish)
  2. `MSS_CONFIRMED` `IS TRUE` [CLOSE] (Reversal is backed by heavy taker volume)
  3. `LOCAL_PRICING` == `PREMIUM` [CLOSE] (Trading in expensive territory)
  4. `PRICE_VS_OPEN` == `ABOVE` [CLOSE] (Trading above True Day Open for premium short entry)
